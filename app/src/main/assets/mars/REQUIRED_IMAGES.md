# Требуемые изображения Марса

Положите реальные фото/иллюстрации Марса (шотландский вислоухий, серебристо-тигровый окрас,
жёлто-оранжевые глаза, сложенные уши) в эту папку с точными именами файлов:

| Файл | Настроение | Описание образа |
|------|------------|-----------------|
| `mars_default.webp` | Спокойный | Нейтральный взгляд, расслабленная поза |
| `mars_done.webp` | Довольный | Смешной и радостный после выполнения задачи |
| `mars_working.webp` | В работе | Серьёзный, задумчивый |
| `mars_postponed.webp` | Перенос | Озадаченный |
| `mars_overdue.webp` | Просрочка | Грозный, но не пугающий |
| `mars_supportive.webp` | Поддержка | Мягкий, поддерживающий взгляд |
| `mars_strict.webp` | Строгий | Требовательный, уважительный тон |

Сейчас в папке лежат временные текстовые заглушки `*.placeholder.txt`.
После добавления `.webp` (или `.png`) файлов приложение подхватит их автоматически.
Рекомендуемый формат: WebP или PNG, квадрат ~512×512 или больше.
