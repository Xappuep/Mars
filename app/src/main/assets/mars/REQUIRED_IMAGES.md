# Изображения Марса

## Прозрачные cutout (основные для UI)

| Файл | Состояние |
|------|-----------|
| `mars_default.webp` | Спокойный |
| `mars_done.webp` | Выполнено |
| `mars_working.webp` | В работе |
| `mars_postponed.webp` | Перенесено |
| `mars_overdue.webp` | Просрочено |
| `mars_supportive.webp` | Мягкая поддержка |
| `mars_strict.webp` | Строгий мотиватор |

Порядок загрузки в приложении: `.webp` → `.png` → `.jpg`.

Cutout создан из исходных PNG (`tools/mars_remove_bg.py`, rembg isnet-general-use): только силуэт кота с alpha-каналом, без фона.

## Исходники (не для прямого отображения в hero)

| Файл | Назначение |
|------|------------|
| `mars_*.png` | Исходные фото с непрозрачным фоном — только для перегенерации webp |

Единый персонаж: шотландский вислоухий, серебристо-тигровый окрас, жёлто-оранжевые глаза.
