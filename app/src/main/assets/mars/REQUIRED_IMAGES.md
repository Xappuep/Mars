# Изображения Марса

Реальные фото подключены из этой папки (не изменять файлы вручную через код).

| Файл | Состояние |
|------|-----------|
| `mars_default.png` | Спокойный |
| `mars_done.png` | Задача выполнена |
| `mars_working.png` | Есть задачи в работе |
| `mars_postponed.png` | Задача перенесена |
| `mars_overdue.png` | Просроченные / невыполненные |
| `mars_supportive.png` | Мягкая поддержка |
| `mars_strict.png` | Строгий мотиватор |

Приложение ищет: `.png` → `.webp` → `.jpg`.

Единый персонаж: шотландский вислоухий, серебристо-тигровый окрас,
жёлто-оранжевые глаза, маленькие сложенные уши — внешность не меняется между файлами.
