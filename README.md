# Ежедневник Марса

Офлайн Android-планировщик на Kotlin (Jetpack Compose + Room).
Все данные хранятся на телефоне. Облака, аккаунтов, рекламы и внешних API нет.

Главный персонаж — **Марс**, шотландский вислоухий кот серебристо-тигрового окраса.
Версия приложения: **1.0.0** (versionCode 1).

## Назначение

Помогает планировать день: задачи с датами и статусами, подзадачи, идеи-дополнения к задачам, календарь и статистика.
Марс реагирует на прогресс мягкими фразами и меняет образ в зависимости от состояния дня.

## Функции (реально работают в v1.0)

- экран **«Сегодня»** с задачами на текущий день, фильтрами и счётчиками;
- **задачи**: создание, редактирование, удаление, статусы (новая, в работе, выполнено, перенесено, не выполнено, отменено);
- **подзадачи** до двух уровней вложенности;
- **дополнения** (идеи улучшений) к задачам;
- **мотиватор Марса** с режимами: выключен, мягкий, адаптивный, строгий;
- **семь визуальных состояний** Марса (фоновое присутствие на главном экране + реакции);
- **предпросмотр образов** в настройках («Образы Марса»);
- **напоминания** по задачам и утренние/вечерние (WorkManager);
- **голосовой ввод** названия новой задачи через системное распознавание речи Android;
- **экспорт JSON** (полный бэкап) и **CSV** (таблица задач);
- **импорт JSON** с объединением или заменой (перед заменой создаётся локальная копия);
- **локальная синхопизация с ПК** через `desktop-sync-server` в одной Wi‑Fi-сети;
- **демо-данные** (загрузка и очистка из настроек);
- **режим уменьшения анимаций**;
- экраны **Задачи**, **Календарь**, **Статистика**, **Настройки**.

## Требования

- Android 8.0+ (API 26+)
- Для сборки: JDK 17, Android SDK 35
- Для sync-сервера на ПК: Python 3.10+

## Сборка debug APK

В корне проекта (Windows):

```bat
gradlew.bat assembleDebug
```

При необходимости укажите `JAVA_HOME` на JDK 17.

Unit-тесты:

```bat
gradlew.bat test
```

Готовый APK:

`app\build\outputs\apk\debug\app-debug.apk`

> Debug-сборка устанавливается с идентификатором `com.mars.planner.debug` (суффикс `-debug` в versionName).

## Установка APK на телефон

1. Скопируйте `app-debug.apk` на устройство.
2. Разрешите установку из неизвестных источников для файлового менеджера или браузера.
3. Откройте APK и установите.
4. При первом запуске разрешите **уведомления** (Android 13+) и **микрофон**, если нужен голосовой ввод.

## Изображения Марса

Каталог: `app/src/main/assets/mars/`

Для интерфейса используются **прозрачные WebP** (основной формат):

| Файл | Состояние |
|------|-----------|
| `mars_default.webp` | Спокоен |
| `mars_done.webp` | Доволен |
| `mars_working.webp` | Сосредоточен |
| `mars_postponed.webp` | Озадачен |
| `mars_overdue.webp` | Просрочено |
| `mars_supportive.webp` | Поддерживает |
| `mars_strict.webp` | Строгий |

Файлы `mars_*.png` — исходники для перегенерации cutout (скрипт `tools/mars_remove_bg.py`).
Подробности: `app/src/main/assets/mars/REQUIRED_IMAGES.md`.

## Синхронизация с ПК (локальная Wi‑Fi)

### Запуск сервера на компьютере

```bat
cd desktop-sync-server
run.bat
```

или:

```bat
cd desktop-sync-server
python -m pip install -r requirements.txt
python server.py
```

Сервер выведет **ключ сопряжения** и порт (по умолчанию `8765`).
Резервные копии с телефона сохраняются в `desktop-sync-server/data/backups/` (каталог не входит в Git).

Узнайте IP компьютера в локальной сети:

```bat
ipconfig
```

(адрес вида `192.168.x.x`).

### Настройка телефона

1. Телефон и ПК — в **одной Wi‑Fi-сети**.
2. В приложении: **Настройки → Синхронизация с ПК**.
3. Введите IP, порт `8765`, ключ сопряжения с экрана сервера.
4. **Проверить подключение** → **Отправить копию на ПК** или **Восстановить с ПК**.

При конфликте версий приложение предложит оставить данные телефона, ПК или объединить.
При ошибке синхронизации данные на телефоне **не затираются**.

## Экспорт и импорт

В **Настройках**:

- **Экспорт JSON** — задачи, дополнения и настройки;
- **Экспорт CSV** — таблица задач;
- **Импорт JSON** — объединение или полная замена.

Файлы сохраняются в каталог приложения на устройстве (`Android/data/.../files`).

## Голосовой ввод

Используется системный `SpeechRecognizer`. Работает только при наличии русского языкового пакета распознавания на устройстве. При недоступности сервис показывает сообщение об ошибке.

## Резервное копирование

| Способ | Где хранится |
|--------|----------------|
| Экспорт JSON в приложении | телефон (`Android/data/.../files`) |
| Отправка на ПК через sync | `desktop-sync-server/data/backups/` на компьютере |
| Импорт JSON | восстановление на телефон |

Рекомендуется периодически выгружать JSON и хранить копию отдельно от репозитория проекта.

## Офлайн-режим

Приложение полностью работает без интернета. Синхронизация — только в локальной сети между телефоном и вашим ПК; наружу данные не отправляются.

## Структура проекта

- `app/` — Android-приложение
- `desktop-sync-server/` — локальный FastAPI-сервер резервных копий
- `app/src/test/` — unit-тесты доменной логики
- `docs/` — чек-листы, отчёты верификации

## Известные ограничения v1.0

- нет облачной синхронизации и аккаунтов;
- голосовой ввод зависит от системного распознавания речи Android;
- sync работает только в одной локальной Wi‑Fi-сети с запущенным сервером на ПК;
- подписанный release APK не входит в этот релиз — только debug-сборка (`com.mars.planner.debug`);
- счётчик «Просрочено» на экране «Сегодня» учитывает только задачи с датой **на сегодня**;
- placeholder-файлы в `assets/mars/` остаются как fallback, если WebP недоступен (в штатной сборке используются WebP).
