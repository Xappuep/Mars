# Ежедневник Марса

Офлайн Android-приложение-планировщик на Kotlin (Jetpack Compose + Room).  
Данные хранятся на телефоне. Облака, аккаунтов, рекламы и внешних API нет.

Главный персонаж — **Марс**, шотландский вислоухий кот серебристо-тигрового окраса.

## Требования

- Android Studio Ladybug / Hedgehog или новее **или** JDK 17 + Android SDK
- Телефон/эмулятор с Android 8.0+ (API 26+)
- Для sync-сервера: Python 3.10+

## Как открыть проект

1. Откройте папку репозитория в Android Studio: `File → Open`.
2. Дождитесь синхронизации Gradle.
3. Выберите конфигурацию `app` и запустите на устройстве/эмуляторе.

## Сборка debug APK

В корне проекта:

```bat
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.0.20.8-hotspot
gradlew.bat assembleDebug
```

Готовый файл:

`app\build\outputs\apk\debug\app-debug.apk`

Тесты:

```bat
gradlew.bat test
```

## Установка APK на телефон

1. Скопируйте `app-debug.apk` на телефон.
2. Разрешите установку из неизвестных источников для файлового менеджера.
3. Откройте APK и установите.
4. При первом запуске разрешите уведомления (и микрофон — если нужен голос).

## Изображения Марса

Каталог: `app/src/main/assets/mars/`

Сейчас там заглушки. Положите реальные файлы:

| Файл | Настроение |
|------|------------|
| `mars_default.webp` | спокойный |
| `mars_done.webp` | довольный |
| `mars_working.webp` | серьёзный |
| `mars_postponed.webp` | озадаченный |
| `mars_overdue.webp` | грозный (без пугающего вида) |
| `mars_supportive.webp` | поддерживающий |
| `mars_strict.webp` | требовательный |

Подробности: `app/src/main/assets/mars/REQUIRED_IMAGES.md`.

## Синхронизация с ПК (локальная Wi‑Fi)

### 1. Запуск сервера на компьютере

```bat
cd desktop-sync-server
run.bat
```

или:

```bat
cd desktop-sync-server
python -m pip install -r requirements.txt
python server.py
```

Сервер напечатает **ключ сопряжения** и порт (по умолчанию `8765`).  
Копии хранятся в `desktop-sync-server/data/backups/`.

Узнайте IP компьютера в локальной сети, например:

```bat
ipconfig
```

(адрес вида `192.168.x.x`).

### 2. Подключение телефона

1. Телефон и ПК должны быть в **одной Wi‑Fi-сети**.
2. В приложении: **Настройки → Синхронизация с ПК**.
3. Введите IP, порт `8765`, ключ сопряжения.
4. Нажмите **Проверить подключение**.
5. **Отправить копию на ПК** или **Восстановить с ПК**.

При конфликте приложение предложит: оставить телефон, оставить ПК или сохранить обе версии.  
При ошибке данные телефона **не затираются**.

## Экспорт и восстановление без сервера

В **Настройках**:

- **Экспорт JSON** — полный бэкап задач и настроек
- **Экспорт CSV** — таблица задач
- **Импорт JSON** — объединение или замена (перед заменой создаётся локальная копия)

Файлы сохраняются в каталог приложения на устройстве (`Android/data/.../files`).

## Голосовой ввод

Используется системный `SpeechRecognizer`. Офлайн работает только при установленном русском офлайн-пакете распознавания речи на устройстве. Если пакет недоступен, приложение честно сообщит об этом и не затрёт уже введённый текст.

## Демо-данные

В настройках можно загрузить и очистить демо-задачи. В обычном запуске они не подставляются автоматически.

## Структура

- `app/` — Android-приложение
- `desktop-sync-server/` — локальный FastAPI-сервер резервных копий
- `app/src/test/` — unit-тесты (статусы, переносы, статистика, экспорт/импорт)

## Приватность

Все данные остаются на вашем телефоне и, при желании, на вашем ПК. Наружу ничего не отправляется.
