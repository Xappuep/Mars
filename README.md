# Ежедневник Марса

Android-планировщик на Kotlin (Jetpack Compose + Room), работающий на модели данных «Рубежа».
Данные хранятся на телефоне; наружу, в интернет, ничего не уходит.
Обмен возможен только напрямую с вашим ПК, на котором запущен «Рубеж», в общей домашней Wi-Fi-сети.

Главный персонаж — **Марс**, шотландский вислоухий кот серебристо-тигрового окраса.

Версия приложения: **2.0.0** (`versionCode 3`). Схема базы — 3. Версия протокола обмена с ПК — 1.

## Модель данных: проекты и задачи

Приложение использует ту же модель, что и «Рубеж» на ПК:

- **Проект** — название, описание, признак архива. Задачи группируются по проектам;
  задача может быть и без проекта.
- **Задача** — заголовок, описание, проект, приоритет (низкий, обычный, высокий),
  срок в виде метки времени и **один из двух статусов**: «Открыта» или «Выполнено».
- У каждого проекта и каждой задачи есть UUID — по нему запись сопоставляется с записью на ПК.

Подзадач, вложенности и отдельной сущности «дополнение» в модели нет.
Данные версий 1.x переносятся автоматически: категории становятся проектами,
подзадачи и дополнения — отдельными задачами с пометкой в описании,
статусы сводятся к двум, дата без времени получает срок 23:59.
Полные правила — `docs/STAGE8_MIGRATION.md`.

## Функции

- экран **«Сегодня»**: задачи на текущий день и просроченные открытые задачи выше остальных, счётчики;
- экран **«Проекты»**: создание, редактирование, архив, прогресс по каждому проекту;
- экраны **«Задачи»**, **«Календарь»**, **«Статистика»**, **«Настройки»**;
- **синхронизация с ПК «Рубеж»** по QR-коду: отправка и приём изменений, разбор расхождений;
- **семь визуальных состояний** Марса и предпросмотр образов в настройках;
- **семь тем «Рубежа»** с регулятором интенсивности эффектов;
- **напоминания** по задачам и утренние/вечерние сводки (WorkManager);
- **голосовой ввод** названия новой задачи через системное распознавание речи Android;
- **выгрузка архива миграции** из Настроек (только если архив есть);
- **режим уменьшения анимаций**.

## Синхронизация с ПК «Рубеж»

Обмен идёт **напрямую** между телефоном и ПК по домашней Wi-Fi-сети, по HTTPS,
с закреплённым сертификатом ПК. Промежуточных серверов нет.

### Как связать телефон и ПК

1. Подключите телефон и ПК к **одной домашней Wi-Fi-сети**. Через мобильный интернет обмен не работает.
2. На ПК: «Рубеж» → «Синхронизация» → «Показать QR-код».
3. На телефоне: «Настройки» → «Синхронизация с ПК» → **«Сканировать QR с ПК»**.
   Если камера недоступна, есть «Вставить код вручную».
4. На ПК подтвердите заявку: в списке появится название телефона, нажмите «Разрешить».
   Телефон подхватит подтверждение сам.
5. Готово: на экране появятся адрес ПК и состояние сопряжения.

### Ежедневная работа

| Кнопка | Что делает |
|--------|------------|
| **Отправить** | передаёт на ПК изменения, сделанные на телефоне |
| **Получить с ПК** | забирает изменения, сделанные на компьютере |
| **Проверить связь** | проверяет, что ПК отвечает и версия протокола совпадает |
| **Разобрать расхождения** | появляется, если запись менялась и там, и там |
| **Разорвать сопряжение** | удаляет ключ доступа; задачи и проекты на телефоне остаются |

На экране видно: состояние сопряжения, адрес ПК, сколько изменений ждёт отправки,
сколько расхождений не разобрано, время последней отправки и последнего приёма.

Полная инструкция есть в приложении: «Синхронизация с ПК» → «Инструкция».

### Что важно знать

- Повторная отправка одних и тех же изменений **не создаёт дублей** на ПК.
- При расхождении данные телефона **не затираются**: показываются обе версии,
  вы выбираете «Оставить телефон» или «Принять ПК».
- Демо-задачи на ПК не отправляются — очистите демо в настройках.
- Ключ доступа хранится в защищённом хранилище телефона (Android Keystore),
  на экране не показывается и в резервные копии не попадает.
- Если сертификат ПК не совпал с закреплённым, обмен прерывается — нужно новое сопряжение.

Технические детали — `docs/STAGE8_SYNC_IMPLEMENTATION.md` и `docs/STAGE8_SECURITY.md`.

## Требования

- Android 8.0+ (API 26+)
- Для сборки: JDK 17, Android SDK 35
- Для обмена: ПК с запущенным «Рубежом» в той же локальной сети

## Сборка debug APK

В корне проекта (Windows):

```bat
gradlew.bat assembleDebug
```

При необходимости укажите `JAVA_HOME` на JDK 17.

Unit-тесты:

```bat
gradlew.bat test
```

Готовый APK:

`app\build\outputs\apk\debug\app-debug.apk`

> Debug-сборка устанавливается с идентификатором `com.mars.planner.debug` (суффикс `-debug` в versionName).

## Установка APK на телефон

1. Скопируйте `app-debug.apk` на устройство.
2. Разрешите установку из неизвестных источников для файлового менеджера или браузера.
3. Откройте APK и установите. Для переноса данных 1.x устанавливайте **поверх**, не удаляя приложение.
4. При первом запуске разрешите **уведомления** (Android 13+), **камеру** — для разового сканирования
   QR сопряжения, и **микрофон**, если нужен голосовой ввод.

## Голосовой ввод

Используется системный `SpeechRecognizer`. Работает только при наличии русского языкового пакета
распознавания на устройстве. При недоступности сервис показывает сообщение об ошибке.

## Офлайн-режим и приватность

Приложение полностью работает без интернета. Обмен возможен только в локальной сети
между телефоном и вашим ПК; наружу данные не отправляются. Аккаунтов, облаков и рекламы нет.

## Известные ограничения 2.0.0

- обмен работает с **одним** ПК, только в общей локальной Wi-Fi-сети и только по нажатию кнопки;
- расхождения разбираются вручную, по одной записи; автоматического слияния нет;
- миграция 1.x → новая модель покрыта только подготовленным инструментальным Room-тестом и требует отдельного запуска на эмуляторе/устройстве;
- `connectedDebugAndroidTest` не запускался без подключённого изолированного тестового устройства;
- подписанный release APK не входит в эту версию — только debug-сборка (`com.mars.planner.debug`);
- голосовой ввод зависит от системного распознавания речи Android;
- сроки, перенесённые из 1.x, посчитаны в часовом поясе устройства на момент миграции;
- legacy `desktop-sync-server` удалён из репозитория в `stage8-corr1`; для синхронизации используется только протокол «Рубеж» v1.
