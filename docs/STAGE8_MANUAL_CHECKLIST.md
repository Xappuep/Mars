# Этап 8 — чек-лист ручной приёмки

**Статус: этап 8 принят по результатам ручной проверки (10.09.2026)
и готов к публикации рабочей ветки.**
Merge в `main`, tag и Release не выполняются этим документом.
Ниже сохранён сценарий; итог заполнен по подтверждённым результатам.

## Что нужно подготовить

- Телефон с Android 8.0+ и рабочей камерой.
- ПК с установленным «Рубежом» (этап 7 и новее, протокол обмена версии **1**).
- Телефон и ПК в **одной домашней Wi-Fi-сети**. Мобильный интернет и гостевая сеть не подходят.
- Если проверяется перенос данных: телефон с **уже установленной** Mars 1.x и реальными задачами,
  а также свежий экспорт JSON из 1.x «на всякий случай».

Отметки: `[x]` — пройдено, `[!]` — замечание, `[ ]` — не проверялось.
Замечания записывайте прямо под пунктом.

## C. Сопряжение с ПК

- [ ] C1. На ПК открыть «Рубеж» → «Синхронизация» → «Показать QR-код».
- [ ] C2. На телефоне: «Настройки» → «Синхронизация с ПК». Состояние — «Сопряжение: не выполнено».
- [ ] C3. Нажать «Сканировать QR с ПК», разрешить доступ к камере, навести на QR.
- [ ] C4. Появилось сообщение «Заявка отправлена. Подтвердите её в «Рубеже» на ПК.»
      и блок «Ждём подтверждения на ПК».
- [ ] C5. На ПК в списке заявок появилось имя этого телефона (производитель и модель).
- [ ] C6. Нажать на ПК «Разрешить». Телефон **сам** (без нажатий) в течение ~3 секунд показал
      «Сопряжение выполнено. Можно отправлять изменения.»
- [ ] C7. На экране появились строки «Адрес ПК» с верным IP и портом и «Сопряжение» с именем ПК.
- [ ] C8. Нажать «Проверить связь» — «ПК на связи, протокол v1».

Отказы:

- [ ] C9. Отказ на ПК («Запретить») → телефон показывает «Сопряжение отклонено на ПК»,
      состояние возвращается к «не выполнено».
- [ ] C10. Дать QR «просрочиться» (показать новый на ПК и сканировать старый) → сообщение
      «Код сопряжения истёк, покажите QR заново».
- [ ] C11. Отсканировать любой посторонний QR (например, ссылку) → «QR-код не подходит для
      синхронизации «Рубеж»», сетевого обращения не происходит.
- [ ] C12. «Вставить код вручную» → вставить текст под QR-кодом с ПК → сопряжение проходит так же.

## D. Отправка изменений на ПК (push)

- [ ] D1. На телефоне создать проект «Проверка этапа 8».
- [ ] D2. Создать в нём три задачи: без срока, со сроком на сегодня, со сроком на завтра и приоритетом «Высокий».
- [ ] D3. Счётчик «К отправке» на экране синхронизации вырос и соответствует числу изменений.
- [ ] D4. Нажать «Отправить» — сообщение «Отправлено изменений: N», счётчик «К отправке» стал «нет изменений».
- [ ] D5. На ПК проект и все три задачи появились с верными названиями, приоритетами и сроками
      (срок совпадает по местному времени телефона).
- [ ] D6. Нажать «Отправить» повторно — «Все изменения уже отправлены», дублей на ПК **нет**.
- [ ] D7. Изменить на телефоне заголовок задачи и отметить одну задачу выполненной, отправить —
      на ПК изменения применились, дублей нет.
- [ ] D8. Удалить на телефоне одну задачу, отправить — на ПК задача удалена.
- [ ] D9. Загрузить демо-данные (Настройки → демо), нажать «Отправить» — демо-проект и демо-задачи
      на ПК **не появились**. Затем очистить демо.

## E. Приём изменений с ПК (pull)

- [ ] E1. На ПК создать проект и две задачи в нём.
- [ ] E2. На телефоне «Получить с ПК» — сообщение «Получено с ПК: новых 3, обновлено 0, удалено 0»
      (число зависит от созданного).
- [ ] E3. Новый проект и задачи появились на телефоне, задачи привязаны к своему проекту.
- [ ] E4. Нажать «Получить с ПК» повторно — «На ПК нет новых изменений», дублей на телефоне **нет**.
- [ ] E5. На ПК изменить заголовок задачи и её срок → «Получить с ПК» → изменения видны на телефоне.
- [ ] E6. На ПК отметить задачу выполненной → «Получить с ПК» → на телефоне статус «Выполнено».
- [ ] E7. На ПК удалить задачу → «Получить с ПК» → на телефоне задача исчезла.
- [ ] E8. Задача с сроком, пришедшая с ПК, появилась на экране «Сегодня», если срок — сегодня,
      и напоминание по ней запланировано.

## F. Расхождения (конфликты)

- [ ] F1. Отключить телефон от Wi-Fi. Изменить **одну и ту же** задачу по-разному на телефоне и на ПК.
- [ ] F2. Вернуть Wi-Fi, нажать «Получить с ПК» — в сообщении есть «Расхождений: 1»,
      на экране счётчик «Расхождения» стал «1».
- [ ] F3. Открыть «Разобрать расхождения» — видны обе версии: «Версия телефона» и «Версия ПК»
      с заголовком, описанием, статусом, приоритетом и сроком.
- [ ] F4. Нажать «Оставить телефон» — локальная версия сохранилась без изменений,
      расхождение исчезло из списка.
- [ ] F5. Повторить F1–F2 на другой задаче и нажать «Принять ПК» — применилась версия ПК.
- [ ] F6. Проверить сценарий «удалено против изменено»: удалить задачу на телефоне,
      изменить её же на ПК, принять данные — появилось расхождение, локальные данные не затёрты.
- [ ] F7. После разбора всех расхождений счётчик показывает «нет», строка «Ошибка» с экрана исчезла.

## H. Безопасность

- [ ] H1. На экране синхронизации нигде **не** показывается ключ доступа;
      внизу есть пояснение, что ключ хранится в защищённом хранилище телефона.
- [ ] H2. Подменить сертификат ПК (перегенерировать его в «Рубеже» без нового сопряжения) →
      любая операция обмена завершается «Сертификат ПК не совпал, соединение прервано»,
      данные на телефоне не изменяются.
- [ ] H3. После нового QR и повторного сопряжения обмен снова работает.
- [ ] H4. Проверить журнал устройства во время полного цикла обмена:
      `adb logcat -d | findstr /i "Bearer token device_token"` — совпадений нет.
- [ ] H5. Проверить настройки приложения на отсутствие ключа в открытом виде
      (файл `shared_prefs/mars_sync_secure.xml` читается только как шифротекст).
- [ ] H6. «Разорвать сопряжение» → подтвердить → состояние «не выполнено»,
      задачи и проекты на телефоне **остались**.
- [ ] H7. После разрыва «Отправить» и «Получить с ПК» недоступны, экран предлагает сканировать QR.
