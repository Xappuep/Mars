# Чек-лист: «ПК — основной» (полный снимок)

**Статус: реализовано в stage8-corr7 (поверх corr6); ручная приёмка на реальных данных НЕ пройдена.**
Не отмечать пункты пройденными без фактического запуска на ПК и телефоне.

Нужны: обновлённый «Рубеж» (**corr7**) и APK Mars **corr7**, одна Wi-Fi, сопряжение.
Протокол поддерживает **несколько активных сопряжённых устройств**: снимок одного телефона не скрывает пакеты от другого; ACK подтверждает пакеты только для запросившего устройства.

## До испытания — счётчики ПК

Записать из **рабочей** базы «Рубежа» (не демо), без подстановки чисел из отчёта:

- [ ] P2. Архивные проекты: ___
- [ ] P3. Открытые задачи: ___
- [ ] P4. Выполненные задачи: ___
- [ ] P5. Задачи без проекта: ___
- [ ] P6. Задачи внутри проектов: ___

## Повторный запрос снимка (corr6+)

- [ ] R1. Запросить первый снимок, **не** подтвердить ACK; запросить второй; после ACK второго старые операции повторно не приходят дельтой.
- [ ] R2. Отменить/сбросить первый снимок на ПК (или дождаться TTL) и запросить новый — новый снимок и ACK успешны.
- [ ] R3. Два активных телефона: снимок телефона A не скрывает изменения от телефона B; ACK A не подтверждает пакеты за B.
- [ ] R4. Изменение на ПК **после** `/snapshot/info` остаётся дельтой и не подтверждается ACK этого снимка.

## Восстановление копии и ACK (corr7)

- [ ] V1. При незавершённом ACK восстановить резервную копию — старый ACK больше не уходит; показан текст про необходимость полной копии.
- [ ] V2. После восстановления «Отправить» и «Получить с ПК» заблокированы; «Получить полную копию с ПК» доступна.
- [ ] V3. После нового полного снимка и успешного ACK дельта снова доступна.
- [ ] V4. Восстановление после уже успешного ACK также требует новый полный снимок (базы не считаются согласованными).
- [ ] V5. Повреждённый HTTP-ответ ACK (`{}`, без `snapshot_id`, неверный тип) не считается успехом; pending ACK сохраняется.

## Дельта после снимка

- [ ] D1. Новая задача на телефоне → «Отправить» → появляется на ПК (один раз).
- [ ] D2. Изменение / выполнение / удаление на ПК → «Получить с ПК» → на телефоне.
- [ ] D3. Старые неподтверждённые операции телефона до снимка **не** уходят на ПК после замены.
- [ ] D4. Изменение на ПК **после** начала полной копии (после info) приходит дельтой ровно один раз и не теряется после ACK снимка.
- [ ] D5. Если подтверждение снимка оборвалось — на телефоне предупреждение и кнопка «Повторить подтверждение»; повтор не дублирует данные; после перезапуска приложения pending ACK восстанавливается из БД.
