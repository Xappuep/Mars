## Почему сохранён BackupCodec

```
SyncCoordinator.applyPcPrimarySnapshot → PhoneSnapshotBackup.createBackup → BackupCodec.toJson
SyncCoordinator.restorePhoneBackup → PhoneSnapshotBackup.restoreLatest → BackupCodec.fromJson
```

Удаление всего кодека сломало бы аварийное восстановление телефона.

## Совместимость старых копий

- Gson по умолчанию игнорирует неизвестные поля JSON (`motivatorMode` в старых файлах)
- Новые копии поле `motivatorMode` не пишут
- Устаревшие ключи DataStore `motivator_mode` / `demo_loaded` при чтении не маппятся; при следующей записи настроек удаляются узкой очисткой

## Результаты ручной приёмки 11.09.2026

1. APK установился обновлением поверх текущей версии; удаление приложения не потребовалось.
2. Проекты, задачи и сопряжение с Rubezh сохранились.
3. После установки скрытых sync-операций не появилось.
4. Из настроек удалены: «Мотиватор Марса», «Экспорт JSON», «Экспорт CSV», «Импорт JSON», «Загрузить демо-данные», «Очистить демо-данные».
5. Сохранены: семь тем, насыщенность эффектов, уменьшение анимаций, «Образы Марса», синхронизация, инструкция, статистика.
6. Марс остался визуальным персонажем; после смены статуса задачи мотивирующее сообщение не появляется.
7. Подраздел «Восстановление» показан (на телефоне есть архив миграции); кнопка «Выгрузить архив миграции» доступна.
8. Текст об уведомлениях внизу настроек присутствует и читается.
9. На экране синхронизации сохранены «Получить полную копию с ПК…» и «Восстановить резервную копию телефона»; на рабочей базе эти операции намеренно не запускались.
10. На чистой очереди: одно изменение статуса → одна sync-операция; после возврата статуса → две ожидающие; обе успешно переданы в Rubezh без конфликтов.
11. Итог на обоих устройствах: 12 активных проектов, 0 архивных, 114 задач, 107 открытых, 7 завершённых; очередь телефона 0; открытых конфликтов 0.
