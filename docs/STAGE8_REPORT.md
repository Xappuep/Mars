## 1. Что реализовано

- Модель проектов и задач, совместимая с «Рубежом».
- Миграция данных Mars 1.x → 2.x (Room + отчёт + архив).
- Сопряжение по QR, TLS с закреплением отпечатка сертификата, токен в защищённом хранилище.
- Полный снимок ПК → телефон (PC-primary), ACK и безопасный режим при повреждённом состоянии.
- Обычный двусторонний обмен пакетами операций: создание, изменение статуса, удаление.
- Защита от дублей по `package_id` / идемпотентность.
- Обнаружение и ручное разрешение конфликтов версий.
- Синхронизация сроков и напоминаний.
- Экраны «Синхронизация с ПК», «Расхождения», «Инструкция»; семь тем «Рубежа».
- Unit-тесты протокола, клиента, снимка, валидации; instrumented-тесты скомпилированы.
